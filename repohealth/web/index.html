🛠️ How to Run RepoHealth on Local Folders & CI/CD

RepoHealth requires zero external dependencies and runs anywhere with standard Python 3.8+.

Audit Current Local Directory:
python repohealth/repohealth.py .
Launch this Web Studio Locally:
python repohealth/repohealth.py --ui
Save Markdown Report:
python repohealth/repohealth.py -o REPO_HEALTH.md
CI/CD Quality Gate (Fail under 80%):
python repohealth/repohealth.py --fail-under 80
