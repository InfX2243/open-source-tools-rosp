# OpenForge Tool Execution Screenshots Directory

Place your test screenshots in this folder with the following filenames:

1. `test_containersec.png` (or `.jpg`) - ContainerSec scan and hardened output
2. `test_curlcraft.png` (or `.jpg`) - CurlCraft web studio with translated code
3. `test_datadiff.png` (or `.jpg`) - DataDiff table diff output in terminal
4. `test_dataguard.png` (or `.jpg`) - DataGuard validation results and quality score
5. `test_jsonformatter.png` (or `.jpg`) - JSON Formatter tree view & auto-repaired JSON
6. `test_scaffoldtree.png` (or `.jpg`) - ScaffoldTree terminal directory creation
7. `test_svg2jsx.png` (or `.jpg`) - SVG2JSX live canvas and generated React TSX component
8. `test_tokencost.png` (or `.jpg`) - TokenCost prompt matrix and multi-model pricing
9. `test_treesnapshot.png` (or `.jpg`) - TreeSnapshot markdown directory tree output
10. `test_envguard.png` (or `.jpg`) - EnvGuard drift audit and secret detection results

When you re-run `python generate_report_docx.py`, these images will be automatically embedded under each tool in Section 4.3!
