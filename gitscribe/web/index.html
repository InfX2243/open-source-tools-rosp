🛠️ How to Add GitScribe to ANY Local Project / Idle Folder

Follow these quick steps to set up automated zero-command changelogs in any folder or repository.

1

Copy the `gitscribe` Folder

Copy the lightweight, zero-dependency gitscribe/ directory directly into your project root. It requires no installation or external packages!

cp -r /path/to/gitscribe/ ./
2

One-Click Auto Hook Setup

Run this command inside your project. It configures Git so that whenever you make a commit, CHANGELOG.md updates automatically!

python gitscribe/gitscribe.py --install-hook
3

Or Run Real-Time Watch Mode

While coding, start the real-time background watcher. As soon as you commit or pull, it immediately regenerates the changelog tables!

python gitscribe/gitscribe.py --watch

⚡ Essential GitScribe CLI Cheat Sheet

Generate Table Changelog:
python gitscribe/gitscribe.py --version v1.0.0
Prepend to Existing CHANGELOG.md:
python gitscribe/gitscribe.py -v v1.1.0 -o CHANGELOG.md -p
Launch this Web Studio Locally:
python gitscribe/gitscribe.py --ui
Generate Machine-Readable JSON:
python gitscribe/gitscribe.py --json -o release.json
