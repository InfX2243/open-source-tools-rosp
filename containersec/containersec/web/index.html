How to Use ContainerSec
A comprehensive guide to auditing, hardening, and automating container security in your development and CI/CD pipelines.
1. CLI Quickstart

ContainerSec works out of the box as a fast terminal tool. Run scans, export in JSON, SARIF, or HTML format, and automate gates.

# Scan default Dockerfile python -m containersec scan # Scan with SARIF output for GitHub Actions python -m containersec scan --format sarif -o report.sarif # Auto-remediate common issues python -m containersec fix --write
2. CIS Docker Benchmark

Enforces industry-standard Center for Internet Security (CIS) rules including non-root execution (CIS 4.1), pinned immutable tags, SSH removal, and cache pruning.

# View all built-in rules & CIS mapping python -m containersec rules
3. CI/CD Quality Gate

Fail pull requests when developers introduce hardcoded secrets or critical vulnerabilities into your container images.

# In your GitHub Actions workflow - name: Security Scan Dockerfile run: | python -m containersec scan --fail-on HIGH

Automated GitHub Actions Integration Example

name: Container Security Gate on: [push, pull_request] jobs: containersec: runs-on: ubuntu-latest steps: - uses: actions/checkout@v4 - name: Set up Python uses: actions/setup-python@v5 with: python-version: '3.11' - name: Install ContainerSec run: pip install . - name: Scan Dockerfile run: containersec scan --fail-on HIGH --format sarif -o containersec.sarif - name: Upload SARIF to GitHub Security Tab uses: github/codeql-action/upload-sarif@v3 with: sarif_file: containersec.sarif
