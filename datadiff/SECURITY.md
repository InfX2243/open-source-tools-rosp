# Security Policy

## Supported Versions
We support the latest version of DataDiff with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within DataDiff, please send an email to the security team or open a private vulnerability advisory on GitHub. We will respond promptly.
