DataDiff User Guide & Documentation

1. What is DataDiff?

DataDiff is an open-source semantic dataset comparison and change detection tool inspired by git diff. Instead of raw text lines, DataDiff understands rows, primary keys, schema migrations, and statistical drift across CSV, JSON, and Parquet files.

2. CLI Commands

# Basic file comparison with a primary key
datadiff compare old.csv new.csv --key id

# Compare Parquet datasets with numeric tolerance
datadiff compare baseline.parquet current.parquet --key customer_id --tolerance 0.01

# Compare Schemas only
datadiff schema old.csv new.csv

# Generate interactive HTML report
datadiff compare old.csv new.csv --key id --format html --output report.html

# Start Web UI & REST API
datadiff serve --port 8001

3. CI/CD Quality Gate Policies

Configure comparison policies in datadiff.yaml to fail automated CI pipelines when forbidden data drifts occur:

policies:
  allow_schema_changes: false
  max_removed_rows: 0
  max_modified_pct: 10.0
  max_null_rate_increase: 5.0
