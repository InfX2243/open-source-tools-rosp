# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The DataGuard team takes security vulnerabilities seriously.

If you discover a security vulnerability within DataGuard, please do **NOT** open a public GitHub issue. Instead, send an email directly to:

📧 **security@dataguard.dev**

Please include:
1. A description of the vulnerability.
2. Steps to reproduce or a Proof of Concept (PoC).
3. The potential impact of the issue.

We will acknowledge receipt of your report within 48 hours and work with you to release a patched version promptly.
